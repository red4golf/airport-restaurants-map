# Phase 2 — Static Airport Pages

This update adds a static HTML page for every airport in your database,
automatically generated by the build script on every run.

## What's included

- `tools/build_geojson.py` — updated build script (replaces your existing one)

That's it. One file. The script generates everything else.

---

## What the build script now produces

On every run (locally or via GitHub Action), the script generates:

1. `data/restaurants.geojson` — unchanged
2. `sitemap.xml` — now includes real airport page URLs (not hash fragments)
3. `index.html` — JSON-LD and hidden SEO list updated (unchanged behavior)
4. `airports/kpwt/index.html` — one page per airport, auto-created
5. `airports/0s9/index.html`
6. `airports/kapa/index.html`
7. ... (one for every airport in your CSV)

Each airport page includes:
- Unique <title>, meta description, and canonical URL
- Open Graph tags
- JSON-LD: Airport schema + FoodEstablishment ItemList + BreadcrumbList
- Mini Leaflet map centered on the airport
- Styled restaurant cards matching the main map design
- Links back to the main map and newsletter

---

## How to deploy

**Step 1** — Replace the build script:
```bash
cp tools/build_geojson.py /your/repo/tools/build_geojson.py
```

**Step 2** — Run the build locally:
```bash
cd /your/repo
python tools/build_geojson.py
```

You should see output like:
```
=== Airport Restaurants Build ===
Fetching OurAirports data…
  Loaded 74,000+ airports from OurAirports.
  Wrote data/restaurants.geojson with 44 features.
  Generated 44 airport pages in /airports/
  Wrote sitemap.xml with 46 URLs.
  Injected updated JSON-LD into index.html.
  Updated SEO restaurant list in index.html.

Done. 44 restaurants · 44 airports · 44 static pages generated.
```

**Step 3** — Commit everything:
```bash
git add tools/build_geojson.py airports/ sitemap.xml index.html data/restaurants.geojson
git commit -m "SEO: Add static airport pages for all 44 airports"
git push
```

GitHub Pages will deploy within ~30 seconds.

## Going forward

Every time you add a restaurant to `data/restaurants_seed.csv` and run the build,
the corresponding airport page is automatically created or updated. No manual work.

If an airport already has a page and you add a second restaurant there,
the page regenerates with both restaurants listed.
